## 03 - PyTorch Autograd

This section covers PyTorch Autograd based on the following tutorial video.

## 📹 Video Source

- **YouTube Tutorial:** [Autograd in PyTorch | Video 3 | CampusX](https://youtu.be/BECZ0UB5AR0)

## 📌 Overview

This tutorial covers PyTorch's Autograd system — automatic 
differentiation for computing gradients. It explains the `requires_grad` 
attribute, how PyTorch builds a computation graph behind the scenes, 
and how `.backward()` is used to automatically calculate gradients for 
tensor operations.
