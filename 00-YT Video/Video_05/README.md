## 05 - PyTorch NN Module

This section covers the PyTorch NN Module based on the following tutorial video.

## 📹 Video Source

- **YouTube Tutorial:** [PyTorch NN Module | Video 5 | CampusX](https://youtu.be/CAgWNxlmYsc)

## 📌 Overview

This tutorial covers PyTorch's `nn.Module` — the base class used to 
build neural network models in a clean, organized way. It explains how 
to define layers, structure a model as a class, and use built-in 
components instead of manually writing raw tensor operations, making 
the training pipeline more professional and reusable.
