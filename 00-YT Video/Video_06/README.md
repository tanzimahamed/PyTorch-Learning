## 06 - Dataset & DataLoader Class in PyTorch

This section covers the Dataset and DataLoader classes in PyTorch based on the following tutorial video.

## 📹 Video Source

- **YouTube Tutorial:** [Dataset & DataLoader Class in PyTorch | Video 6 | CampusX](https://youtu.be/RH6DeE3bY6I)

## 📌 Overview

This tutorial covers PyTorch's `Dataset` and `DataLoader` classes, which are used to efficiently manage and load datasets during model training. It explains how to create custom datasets, organize data into batches, shuffle data, and use `DataLoader` to build a clean and efficient data pipeline for neural network training.
