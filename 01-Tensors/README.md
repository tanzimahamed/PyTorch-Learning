# 01 - PyTorch Tensors

This section covers the fundamentals of PyTorch Tensors, which are the core building blocks and primary data structures used in PyTorch for machine learning and deep learning applications.

## 📋 Topics Covered

- **Tensor Basics:** Understanding what tensors are and how they differ from NumPy arrays.
- **Tensor Creation:** Creating tensors from Python lists, NumPy arrays, and built-in functions (`torch.zeros`, `torch.ones`, `torch.rand`).
- **Data Types & Devices:** Managing tensor data types (`dtypes`) and transferring tensors between CPU and GPU (`CUDA`).
- **Operations & Manipulation:** Indexing, slicing, reshaping, joining, and performing basic arithmetic operations.

## 📁 Files in this Folder

- `tensors_in_pytorch.ipynb`: Interactive Jupyter Notebook containing hands-on code examples and operations on PyTorch tensors.
